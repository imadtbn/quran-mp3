# خدمة إشعارات الصلاة (Backend)

هذه الخدمة **غير منشورة تلقائيًا** من GitHub Pages. تحتاج استضافة Node.js دائمة مع قرص دائم و HTTPS عبر reverse proxy.

1. `npm install`
2. توليد زوج VAPID: `npx web-push generate-vapid-keys`
3. نسخ `.env.example` إلى متغيرات بيئة الاستضافة ووضع المفاتيح فيها (لا ترفع المفتاح الخاص إلى GitHub).
4. إعداد `ALLOWED_ORIGIN=https://imadtbn.github.io`، و`VAPID_SUBJECT` عنوان بريد مسؤول الخدمة.
5. نشر الخدمة على HTTPS وضبط رابطها في `assets/data/prayer-push-config.json`.
6. يجب استخدام persistent disk لقاعدة SQLite وتشغيل **نسخة واحدة فقط** من العامل المجدول. للخدمات متعددة النسخ استخدم قاعدة مركزية مع قفل موزع.
7. اختبار إنشاء الاشتراك، إلغائه، وصول إشعار الفجر في الخلفية، واختبارات القفل والإغلاق على Android وiPhone.

ملاحظة: لا ينبغي إعلان جاهزية الخلفية حتى نجاح اختبار فعلي للهاتف. تُحتفظ الإحداثيات وبيانات Push على الخادم لإرسال التذكيرات؛ يجب نشر سياسة خصوصية وفترة احتفاظ وحذف صريحة قبل تفعيل الخدمة للجمهور. لا ترفع ملفات قاعدة البيانات أو مفاتيح VAPID.

### النقاط البرمجية
- `GET /health`
- `GET /api/public-key`
- `POST /api/subscriptions` — تحديث الاشتراك وتفضيلات الصلاة.
- `DELETE /api/subscriptions` — حذف الاشتراك بواسطة endpoint.

**تنبيه أمني:** الواجهة الحالية نموذج أولي؛ تحقق من وجود حدود للطلبات وحماية اشتراكات المستخدمين قبل الإطلاق العام.
